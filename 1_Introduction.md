# <center> INTRODUCTION

### **HISTORY -**  

Before JavaScript (1995), Even if you forgot to enter your username, the browser still had to contact the server,  
Slow websites, Full page reloads, Poor user experience  

In 1995, the company Netscape wanted web pages to become interactive.
So they hired a programmer named Brendan Eich.

Brendan Eich built the first version of JavaScript in just 10 days. 

Initially, it was called :-  
Mocha -> LiveScript -> JavaScript

**What JavaScript originally did ?**  
It only ran inside the browser, like showing alert if clicked on button, if password left empty then showing "Password is required"   
No server request needed, That made websites feel much faster.
